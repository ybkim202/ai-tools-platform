# AITools — 브랜드 네이밍 탐색 기록 (Naming PRD)

> 작성일: 2026-06-22 · 성격: 리브랜딩 네이밍 후보 탐색·경쟁사 분석·충돌 스크리닝의 **단일 기록**.
> 상태: **이름 미확정.** 안전 후보 풀(🟢)과 평가 기준을 박제해, 추후 확정 시 즉시 메타·로고·태그라인·보이스 정렬로 넘어가기 위함.
> ⚠️ 모든 도메인/충돌 판정은 **웹 1차 스크리닝**이며 WHOIS 실조회·상표 DB(KIPRIS/USPTO/EUIPO) 실검색을 **대체하지 않는다.** 확정 전 정식 상표 클리어런스(클래스 9·42) 필수.

---

## TL;DR

- **왜**: 현재 제품명 `AITools`는 제너릭하고, 메타데이터는 CRA 기본값(`React App`)이 방치돼 있음. 브랜딩 정렬의 기둥인 **네이밍**부터 정리.
- **결론(시장 진단)**: AI 도구 디렉토리/SaaS 네임스페이스는 **포화**. `AI/future/-pedia/tools/hunt` 클리셰 + `.ai` TLD까지 차별 신호가 죽었다. 짧은 실단어·라틴/그리스 어근은 대부분 선점됨.
- **빈 공간(white space)**: "규모(백과사전)·발굴(사냥)"이 아닌 **"선별·판단·적합(현명한 선택을 도와준다)"** 톤의 짧은 브랜드. 우리 차별점(벤치마크 비교 + 매칭강도 추천)과 정합.
- **산출물**: 4라운드 스크리닝 끝에 트레이드마크 기준 **🟢 안전 후보 16개 확보 → 큐레이션 10선**. 추천 1위 **Cernix**.

## 1. 배경 — 현재 브랜드 상태 (fact)

| 항목 | 현 상태 | 문제 |
|---|---|---|
| 제품명 | `AITools` (코드 전반) | 제너릭·검색 차별성 0 |
| `frontend/public/manifest.json` | `"React App"` / `"Create React App Sample"` | CRA 기본값 방치 |
| `frontend/public/index.html` `<title>` | `React App` | CRA 기본값 방치 |
| theme-color | `#000000` | 디자인 토큰과 별개 하드코딩 |
| 로고 소스 | `logo/ai-tools-platfrom.ai` (+png/svg) | **파일명 오타(`platfrom`)** |
| 헤더 로고 | CSS mask + 잉크 토큰(라이트/다크 자동 반전) | 워드마크 정체성 없음 |

> 메타데이터 정비(`React App` → 실제 브랜드명 + OG 태그)는 **이름 확정과 무관하게 즉시 가능한 저비용 작업**. 단, 브랜드명이 들어가야 의미가 있어 네이밍에 종속.

## 2. 경쟁사 네이밍 지형

| 유형 | 대표 | 톤 |
|---|---|---|
| 서술형(문장/전치사) | There's An AI For That(TAAFT), Future Tools, AlternativeTo, RankmyAI | 검색의도 직설 (SEO형) |
| 백과사전 조어 | Futurepedia, Capterra, AIxploria | 규모·권위 |
| 발굴 메타포 | Product Hunt | 사냥·선별 |
| 신뢰/판단 조어 | G2, Slant, TrustRadius | 의견·권위 |

**시장 클리셰(회피 대상)**: `AI` 접두/접미(+`.ai` TLD 포화), `future-`, `-pedia`, `tools/hunt/finder`.
**경향**: 디렉토리는 서술형, 리뷰·비교는 조어/메타포형 — "검색을 팔면 서술형, 판단을 팔면 조어형."
**부수 발견**: Insidr.ai가 "78+ categories" 카피 사용 → 우리 랜딩은 "78개" 대신 **"벤치마크로 비교"** 같은 기능 차별 메시지를 전면에.

## 3. 스크리닝 기준

- 🟢 **안전(트레이드마크 기준)** = ① AI/SaaS/테크 분야 직접 동명·동음 없음 ② 유명 글로벌 대형 브랜드 충돌·혼동 없음 ③ 타 언어 비속어·부정 연상 없음. **이종업종(식품·패션·지역업체)의 소규모 동음은 허용**(상표 클래스 상이 시 실사용 지장 적음).

### 추천 숏리스트 (의미 정합성+발음+브랜드성)
1. **Cernix** — 분별 어근 + `-ix` 균형 최상. **종합 1위.**
2. **Vetqo** — "도구를 vet한다" = 비교·추천 본질 직결.
3. **Pikvo** — "고른다" 직관·경쾌.
4. **Cerqo** — `-qo`에서 큐레이션 뉘앙스.
5. **Judra** — 판단·평가, 차분한 신뢰 톤.
