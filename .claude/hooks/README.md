# 세션 기록 훅 (팀 공유)

Claude Code 세션의 연속성을 위한 훅 3종. `.claude/settings.json`에 등록되어 레포를 클론한 팀원 모두에게 적용된다(첫 사용 시 Claude Code가 훅 실행 승인을 요청함).

| 훅 | 시점 | 동작 |
|---|---|---|
| `session_start.sh` | 세션 시작 | 내 지난 세션 로그(최근 200줄)를 컨텍스트로 주입 |
| `stop.sh` | 대화 종료(세션당 1회) | 이번 세션의 한 일·배운 점·다음 할 일을 로그에 기록하게 함 |
| `precompact.sh` | 컨텍스트 압축 직전 | 압축으로 사라지기 전 핵심 요약을 로그에 보존하게 함 |

## 로그는 개인용, 메커니즘만 공유 (하이브리드)

- 로그 파일: `.claude/local/session-log.md` — **gitignore 됨.** 팀원마다 자기 머신에 자기 로그가 쌓인다. 머지 충돌·PR 노이즈 없음.
- 팀과 공유할 가치가 있는 학습(컨벤션·함정·운영 절차)은 로그에 묻어두지 말고 **`docs/`의 해당 정본 문서에 수동으로 승격**한다. Stop/PreCompact 훅 프롬프트가 이 승격을 제안하도록 되어 있다.

## 요구사항

- `bash`, `jq` (macOS/Linux 기본 또는 `brew install jq`)
- 개인 훅(예: 데스크톱 알림)은 `.claude/settings.local.json`에 두면 커밋되지 않는다.
